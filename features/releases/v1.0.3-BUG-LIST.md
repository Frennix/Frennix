## How to add an issue

1. Assign the next ID: `BUG-002`, `BUG-003`, … (or `ENH-001` for enhancements).
2. Add a row to **Open issues** above.
3. Mirror the row in [`RELEASE.md`](./RELEASE.md) → v1.0.3 → Bug fixes.
4. Fix only after the row exists with priority and reporter.

### Priority guide

| Severity | When to use |
|----------|-------------|
| **Critical** | Core flow broken for most users |
| **High** | Major feature degraded |
| **Medium** | Partial impact or workaround exists |
| **Low** | Cosmetic or rare edge case |
